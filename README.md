# Fiscal Transmission in a Two-Agent New Keynesian (TANK) Model

This repository contains the implementation of a Two-Agent New Keynesian (TANK) model used to study the macroeconomic effects of fiscal policy under household heterogeneity.

## Overview

The project investigates how the transmission of fiscal policy changes with different shares of liquidity-constrained households and alternative fiscal transfer regimes.

The analysis compares multiple model calibrations to evaluate the dynamic responses of key macroeconomic variables under different policy scenarios.
